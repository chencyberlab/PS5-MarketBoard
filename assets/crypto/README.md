# Bundled token icons

128×128 transparent color PNGs from [spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons),
revision `1a63530be6e374711a8554f31b17e4cb92c25fa5`, directory `128/color`.
The images are unmodified and distributed under CC0 1.0; see `LICENSE-CC0.txt`.

Bundled symbols: BTC, ETH, SOL, XRP, DOGE, USDT.
The Linux build overlays this directory at `/app0/assets/crypto`.
Keep uppercase filenames consistent with `bundled_icon()` in `market_icon_core.cpp`.
